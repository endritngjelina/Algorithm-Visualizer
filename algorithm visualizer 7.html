About Merge Sort Merge Sort divides the array into halves, sorts them separately, and merges them back together.

Merge Sort is a divide-and-conquer algorithm that divides the array into halves, sorts them separately, and then merges them back together. It's efficient for large datasets and guarantees O(n log n) performance.
